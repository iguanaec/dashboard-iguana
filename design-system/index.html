Iguana Design System · v0.1.0

Claro, suave y sin líneas rectas.

Un solo sistema para el panel, la web y lo que venga: tokens de color con la cromática verde de Iguana, formas redondeadas, colores que la gente ya entiende (verde bien, rojo mal, ámbar ojo) y elementos que responden al tocar.

Principios

Cinco reglas que explican todas las decisiones del sistema. Si dudas, vuelve aquí.

01

Claro primero

Fondo verde‑gris muy suave, tarjetas blancas y mucho aire. Lo importante se destaca con tamaño y un toque de lima, no con adornos.

02

Sin líneas rectas

Nada de divisores, tablas con rejilla ni bordes de tarjeta. Se separa con espacio, tono y sombra suave. Todo tiene esquinas redondeadas; los conectores son punteados.

03

Una cromática

Verde Iguana como protagonista, lima como resalte y neutros con un toque verde. Sin cafés ni beige. Los datos usan la misma familia.

04

Colores que ya conoces

Verde = bien, rojo = error o pérdida, ámbar = atención, azul = información. Nunca se usa solo el color: siempre va con icono o palabra.

05

Todo responde

Al pasar el cursor o tocar, cada cosa reacciona: se eleva, se desliza, gira o cuenta. Movimiento con sentido, 160–400 ms, y respeta “reducir movimiento”.

Color

Haz clic en cualquier muestra para copiar su valor. Cada color tiene un nombre de token; los componentes usan solo los semánticos.

Marca · verde Iguana

Ancla #0C7A3E (600). El 900 es el botón principal y las superficies oscuras; el 50–100 son fondos suaves.

Resalte · lima

La “energía” de la marca. Solo para lo que debe verse primero: elemento activo, tarjeta destacada, el día pico. Siempre con texto oscuro encima.

Neutros · mist

Grises con un toque verde: se sienten de la misma familia y no tiran a beige ni café como el gris cálido anterior.

Movimiento

Rápido y con carácter. Los resortes (spring) se usan para lo que “rebota” al aparecer; las curvas de salida suave para el resto.

Duraciones: instant 90 · fast 160 · base 240 · slow 400 · slower 640 ms

Pasar el cursor

Sube 1–4 px y la sombra crece. Los iconos de acción giran o se agrandan con resorte.

Presionar

Se encoge a 0,97 durante 90 ms: se siente físico y confirma el toque.

Aparecer

Menús, avisos y diálogos entran con escala 0,94 y resorte. Las hojas móviles suben desde abajo.

Iconos

Trazo de 1,75 px, puntas y uniones redondeadas, 20 px por defecto. Un solo estilo: siempre contorno, nunca relleno mezclado. Clic para copiar el nombre.

Accesibilidad

Se valida con cada cambio de token. Lo mínimo que cumple todo componente:

  • Texto con contraste ≥ 4,5:1 y controles/gráficos ≥ 3:1 (ver “Pares aprobados”).
  • El color nunca va solo: estados, deltas e importes llevan icono, signo o palabra.
  • Zonas táctiles de 44 px o más y 8 px entre ellas.
  • Foco visible con resplandor suave y contorno; todo se maneja con teclado (flechas en selectores, menús y gráficos).
  • Se respeta prefers-reduced-motion: las animaciones pasan a cambios instantáneos.
  • Campos con etiqueta visible, ayuda y error con icono y texto, 16 px mínimo en móvil.

Cómo usarlo

Tres archivos y una clase. Funciona en cualquier app, sin compilar nada.

<link rel="stylesheet" href="design-system/tokens.css">
<link rel="stylesheet" href="design-system/components.css">
<script src="design-system/ig.js" defer></script>

<body class="ig-root">   <!-- fuente, color de fondo y texto -->

Reglas

Usa solo tokens --ig-color-* en tus estilos. Si necesitas un color nuevo, se agrega al sistema, no a tu pantalla.

Otras apps

tokens.json se genera con node design-system/export-tokens.mjs a partir de tokens.css, para llevarlo a Figma, React Native o Flutter.
